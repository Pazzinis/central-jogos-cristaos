# Monte — Central de Jogos Cristãos

Uma central de jogos cristãos para jogar em grupo pelo celular.

O primeiro jogo, **Quem Sou Eu?**, traz três dificuldades, 54 personagens bíblicos, contagem sonora, partidas de 60 segundos e controle por inclinação do celular. Também há botões de toque e teclado como alternativa.

Projeto estático pronto para GitHub Pages.
