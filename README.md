# Monte — Central de Jogos Cristãos

Uma central de jogos cristãos para jogar em grupo pelo celular.

O primeiro jogo, **Quem Sou Eu?**, traz três dificuldades, 54 personagens bíblicos, contagem sonora e controle por inclinação do celular. O nível fácil dura 3 minutos, o médio 2 e o difícil 1. Cada rodada usa uma roleta animada e protege a troca de personagem com uma contagem de 3 segundos. Também há tela cheia, botões de toque e teclado como alternativas.

Projeto estático pronto para GitHub Pages.
