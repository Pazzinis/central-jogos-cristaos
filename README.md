# Monte — Central de Jogos Cristãos

Uma central com onze jogos cristãos para família, célula e amigos.

Inclui **Quem Sou Eu?**, Mímica Bíblica, Desenho Bíblico no papel, Complete o Versículo, Verdadeiro ou Falso, Quem Disse Isso?, Bíblia em 5 Pistas, Palavra Proibida, Batalha de Perguntas, Emoji Bíblico e O Infiltrado.

Os jogos compartilham cronômetros, pontuação, roleta, equipes, tela cheia e uma interface responsiva. O Quem Sou Eu? usa somente personagens conhecidos em todos os ritmos; a escolha altera apenas o tempo da partida.

Projeto estático pronto para GitHub Pages.
